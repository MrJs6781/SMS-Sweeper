# SMS Sweeper

اپ اندروید (Kotlin + Compose) برای مدیریت و حذف دسته‌ایِ پیامک‌ها، با رابط فارسی و تقویم شمسی.

## امکانات
- **فیلتر ترکیبی (AND):** نوع (دریافتی/ارسالی)، قبل از تاریخ، بازه‌ی تاریخی، قدیمی‌تر از N روز، فرستنده، متن (با regex اختیاری)، خوانده/نخوانده، اسپم، و «قدیمی‌ترین N تا / نگه‌داشتن آخرین N تا». تعداد پیامک‌های مطابق به‌صورت زنده نمایش داده می‌شود.
- **تقویم شمسی کامل** برای انتخاب تاریخ.
- **تب فرستنده‌ها:** مرتب‌شده بر اساس تعداد، با حذف یک‌لمسی، محافظت و بلاک.
- **تب آمار:** مجموع‌ها، نمودار ۱۲ ماه اخیر (ماه شمسی)، پرپیامک‌ترین فرستنده‌ها.
- **لیست‌ها:** فرستنده‌های محافظت‌شده (هرگز حذف نمی‌شوند)، فرستنده‌های بلاک، کلمات اسپم دلخواه.
- **قانون‌های ذخیره‌شده (Preset)** و **پاکسازی خودکار** روزانه/هفتگی با WorkManager.
- **پشتیبان و سطل بازیافت:** پیش از هر حذف یک نسخه‌ی JSON ذخیره می‌شود (۷/۳۰/۹۰ روز)، با «بازگردانی» فوری و بازیابی از سطل. خروجی/ورودی فایل برای کل پیامک‌ها.

## دریافت APK
- هر پوش بیلد می‌گیرد: تب **Actions** ← اجرا ← **Artifacts**.
- لینک مستقیم برای گوشی: تگ بزن (`git tag v1.1; git push origin v1.1`) تا APK در **Releases** منتشر شود (نسخه از روی تگ تعیین می‌شود).

## نکات مهم
- اندروید فقط به «برنامه‌ی پیش‌فرض پیامک» اجازه‌ی حذف می‌دهد؛ اپ موقتاً پیش‌فرض می‌شود. بعد از پاکسازی برنامه‌ی قبلی را برگردانید (MMS ذخیره نمی‌شود). پاکسازی خودکار هم فقط وقتی کار می‌کند که اپ در آن لحظه پیش‌فرض باشد.
- روی اندروید ۱۳+ برای اپ‌های نصب‌شده از بیرون فروشگاه ممکن است لازم باشد در *App info ← ⋮ ← Allow restricted settings* را بزنید.
- تشخیص اسپم بر پایه‌ی کلمات کلیدی است (`Core.kt`)؛ پیامک‌های کد/رمز هرگز اسپم حساب نمی‌شوند.

## امضای release با کلید ثابت (اختیاری، پیشنهادی)
بدون کلید، APK با کلید debug (کش‌شده) امضا می‌شود. برای کلید واقعی (JDK یا Android Studio لازم است):

```powershell
keytool -genkeypair -v -keystore release.jks -alias sweeper -keyalg RSA -keysize 2048 -validity 10000
[Convert]::ToBase64String([IO.File]::ReadAllBytes("release.jks")) | gh secret set KEYSTORE_B64
gh secret set KEYSTORE_PASSWORD
gh secret set KEY_ALIAS
gh secret set KEY_PASSWORD
```

فایل `release.jks` را حتماً جای امن نگه دار (گم‌شدنش یعنی دیگر نمی‌شود اپ را آپدیت کرد) و هرگز کامیت نکن. با تغییر کلید، یک‌بار باید نسخه‌ی قبلی نصب‌شده را پاک کنی.
