# SMS Sweeper

اپ اندروید برای حذف دسته‌ایِ پیامک‌ها: قبل از یک تاریخ، بازه‌ی تاریخی، تعداد (قدیمی‌ترین N تا / نگه‌داشتن آخرین N تا)، اسپم، و بر اساس فرستنده یا متن. همیشه قبل از حذف پیش‌نمایش نشان می‌دهد.

## دریافت APK
- هر پوش روی `main` بیلد می‌گیرد: تب **Actions** ← آخرین اجرا ← **Artifacts** ← `SMS-Sweeper`.
- برای لینک مستقیم دانلود روی گوشی یک تگ بزن (`git tag v1.0 && git push origin v1.0`)؛ APK در **Releases** قرار می‌گیرد.

## نکات مهم
- اندروید فقط به «برنامه‌ی پیش‌فرض پیامک» اجازه‌ی حذف می‌دهد؛ اپ از شما می‌خواهد موقتاً پیش‌فرض شود. بعد از پاکسازی، برنامه‌ی قبلی را برگردانید (MMS در این اپ ذخیره نمی‌شود).
- روی اندروید ۱۳+ برای اپ‌های نصب‌شده از بیرون از فروشگاه، ممکن است لازم باشد در *App info ← ⋮ ← Allow restricted settings* را بزنید.
- بیلد با کلید debug امضا می‌شود؛ کلید بین بیلدها کش می‌شود تا نسخه‌ی جدید روی قبلی نصب شود.
- تشخیص اسپم بر پایه‌ی کلمات کلیدی است (`Core.kt`)؛ پیامک‌های کد/رمز هرگز اسپم حساب نمی‌شوند.

## ساخت محلی
Android Studio پروژه را باز کن (Gradle 8.9 / JDK 17).
